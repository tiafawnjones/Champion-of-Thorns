# Tia Jones author website

Static GitHub Pages site for https://tiajonesbooks.com. Main branch, repository root.

## Preview
Run `python3 -m http.server 8000` in this directory. Open http://localhost:8000.
No package installation or build step is required. The site works without JavaScript.

## Assets
- `assets/enchanted-oak.webp`: generated woodland hero, optimized WebP.
- `assets/thorn-blossoms.webp`: generated transparent botanical ornament.
- `assets/writers-window.webp`: generated decorative writing-desk scene, not a photograph of Tia or her workspace.
- `assets/flower.svg`, `assets/favicon.svg`: original seven-petal vector motif.
- `assets/paper.svg`: lightweight procedural paper texture.
- `assets/site.css`: shared responsive styling.

The final cover was not used or modified. Cover placeholder is styled HTML. Existing prepublication description and tentative date are retained; review destinations remain pending until actual book URLs are verified. Newsletter signup is intentionally not displayed until an actual hosted signup form is available, so visitors cannot submit email addresses into a nonfunctional form.

Generated raster imagery was created with the built-in image generation tool for this authorized redesign. No third-party stock imagery or external fonts are required. Full generation prompts are recorded in `ASSET-PROMPTS.md`.
